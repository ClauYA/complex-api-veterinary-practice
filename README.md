# 🐾 Project: Veterinary Practice

Visit Prep is a front-end web app that helps new dog owners prepare for a veterinary visit.

Users select a dog breed from the Dog CEO API. The app uses the selected breed information to search TheDogAPI for additional breed details, then generates a simple veterinary visit-preparation handout.

## Project Goal

Build a front-end app that uses data returned from one API to make a request to another API and create something useful for a veterinary practice.

## Features

- Browse dog breeds and sub-breeds.
- Select a dog breed.
- Retrieve detailed breed information.
- Display general breed details, including:
  - Breed group
  - Typical weight
  - Typical height
  - Life span
  - Temperament
  - Description
  - Add the dog’s name and reason for visit.



  - Dog CEO API: Dog CEO provides a free list of dog breeds and sub-breeds.
  [https://dog.ceo/api/breeds/list/all]
  - TheDogAPI : TheDogAPI provides detailed information about dog breeds.
  [https://api.thedogapi.com/v1/breeds/search?q={breedName}]

  > Note:
This tool provides general breed information only. It does not diagnose health conditions or replace personalized advice from a licensed veterinarian.
